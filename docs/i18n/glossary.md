# Terim Sözlüğü / Glossary (TR ↔ EN)

Çeviride bu tablo bağlayıcıdır. Yeni bir terim gerekirse önce buraya eklenir, sonra kullanılır.
Türkçe tarafta mevcut terimler korunur; İngilizce tarafta ABD İngilizcesi kullanılır.
Uygulamanın İngilizce adı: **Algorithm Learning** (Türkçe: Algoritma Öğrenme).

## Sözde kod anahtar kelimeleri (Türkçenin birebir aynası)

| Türkçe | English |
|---|---|
| OKU / YAZ | READ / WRITE |
| EĞER / DEĞİLSE / BİTİR | IF / ELSE / END |
| İÇİN i ← 1'DEN 5'E ADIM 1 … DÖNGÜ_BİTİR | FOR i ← 1 TO 5 STEP 1 … END_LOOP |
| SÜRECE … DÖNGÜ_BİTİR | WHILE … END_LOOP |
| DOĞRU / YANLIŞ | TRUE / FALSE |
| VE / VEYA / DEĞİL | AND / OR / NOT |
| SABIT | CONST |
| div / mod | DIV / MOD |
| FONKSİYON / DÖNDÜR | FUNCTION / RETURN |

Not 1: Kod çalıştırıcı yalnızca bu tablodaki komutları çalıştırır. `DURUM` (CASE) ve `YAP...SÜRECE` (DO-WHILE)
derslerde yalnızca kavram olarak anlatılır, çalıştırılabilir değildir; İngilizcede de öyle kalır
(`CASE`, `DEFAULT`, `DO ... WHILE` yalnızca metinde ve alıştırma seçeneklerinde geçer).

Not 2: Anahtar kelime tablosu dile göre seçilir. Türkçe derslerde `not` bir değişken adıdır
(`not ← 45`); İngilizce `NOT` yalnızca İngilizce derslerde anahtar kelimedir. Bu yüzden İngilizce çeviride
bu değişken `grade` olur. Aynı çakışma `to`, `end`, `step`, `if`, `read`, `write`, `or`, `and`, `const`,
`mod`, `div`, `true`, `false`, `function`, `return`, `while`, `for`, `else` adları için de geçerlidir:
bunlar İngilizce derslerde değişken adı olarak KULLANILMAZ.
